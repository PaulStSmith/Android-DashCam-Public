We're recruiting Beta users to test the initial version of the DashCam app by ByteForge, available for Android 8.0 or later.

DashCam turns your phone into a smart dash camera — it records automatically when the car powers on, detects impacts, and can upload videos to Google Drive, OneDrive, or your local network.

Key Features

  • Automatic recording tied to ignition or impact detection
  • Impact detection with circular video buffer (saves 2 min before + 10 sec after)
  • Rich telemetry: GPS, speed, and 6‑axis motion sensor logging
  • Flexible uploads: Windows shared folder (SMB/CIFS) or cloud (Google Drive, OneDrive)
  • Multiple output formats: MP4 video, SRT subtitles, CSV sensor data, GPX tracks
  • Automatic storage management: configurable auto‑cleanup when space is low
  • Queued uploads: automatic retries with background processing
  • Secure credentials: encrypted storage via Android Keystore
  • NetBIOS support: use Windows hostnames instead of IP addresses
  • Battery‑friendly: designed for continuous operation with minimal power usage
  • Hands‑off operation: set it up once, drive daily — no interaction required
